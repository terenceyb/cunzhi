# PRD 增补 v2.6 —— Apple 设计语言与启动页

> 范围：全站（桌面 + 移动）版式统一到 Apple 设计语言；启动页版式重做与首次使用引导。
> 断点沿用 `max-width: 767px`，桌面指 `≥768px`。

---

## 0 做法：一层覆盖，不动功能

新增 `src/styles/apple.css`，在 `main.tsx` 里**最后**引入。所有规则只覆盖视觉属性
（颜色、圆角、阴影、间距、字号、控件形态），不碰任何交互实现：

- 拖拽重排、弹性面板、卡堆叠放、玻璃标签栏、InlineTextMorph 全部原样保留；
- 同特异性下后者生效，因此 `app.css` / `pages.css` 一行未改；
- 回滚只需要去掉 `main.tsx` 里的一行 import。

这一层也顺手把变量重定义了，所以换主题色（素白 / 云母 / 靛蓝 …）与深浅模式会自动跟随。

## 1 设计 Token

| 项 | 旧 | 新 | 理由 |
|---|---|---|---|
| 背景 | `#f3f4f6` | `#f2f2f7` | iOS `systemGroupedBackground`，白底卡片压得住 |
| 正文 | `#131619` | `#1c1c1e` | iOS `label` |
| 次要文字 | `#6b7583` | `#8a8a8e` | iOS `secondaryLabel` |
| 分隔线 | `#e6e8ec` | `rgba(60,60,67,.10)` | iOS separator，深浅模式同一套语义 |
| 圆角 | 8 / 10 / 14 / 20 / 26 | 9 / 11 / 16 / 18 / 24 | 三档：控件 10、卡片 18、浮层 24 |
| 动效曲线 | `cubic-bezier(.16,1,.3,1)` | `cubic-bezier(.32,.72,0,1)` + 320ms | Apple 的减速曲线，起手快、收尾稳 |

深色模式单独一套：背景纯黑 `#000`、卡片 `#1c1c1e`、分隔线白色 10%。

## 2 层次：底色差 + 发丝线，不用实线框

之前几乎每个容器都是 `1px solid var(--line)`，页面读起来像后台系统。现在：

- **卡片**：`border: 1px solid transparent` + `box-shadow: 0 0 0 .5px var(--card-edge), 0 1px 2px …, 0 10px 26px -18px …`；
  边缘变成半像素发丝线，阴影只做「微微离开纸面」。
- **控件**（按钮 / 输入框）：保留可见边界，但用「1px 15% 文字色」而不是灰线，
  输入框在白底上不再飘。
- **去掉装饰竖条**：`.section-title h3::before`、`.detail-section-head h4::before` 的彩色渐变竖条关掉，
  改由字重与留白分节。

## 3 外壳

- **侧栏**：`color-mix(surface 55%, bg)`，比内容区亮一档；选中项白底 + 半像素描边 + 极淡投影。
- **顶栏**：76% 不透明毛玻璃（`blur(24px) saturate(180%)`），54px 高。
- **内容轴**：`.page` 1100px、`.ix-page` 1020px（互动页行长收到 850px 左右）。
- **大标题**：`clamp(23px, 1.5vw+13px, 30px)` / 700 / `-0.032em`，副标题 13.5px `text-3`。
  首页、互动页走 `PageHead`；人脉页新增 `.people-head`（移动端隐藏，顶栏已有标题）。
- **人脉页对齐**：卡堆 `max-width` 640，工具栏与标题的 `padding-inline` 用
  `max(18px, calc((100% - 640px)/2))`，三者落在同一条轴上。

## 5 启动页

### 5.1 中轴对称

`.land` 用 `flex + align-items/justify-content: center`，`.land-inner` 加 `margin: auto`：
内容比视口矮时严格垂直居中，高时自然从顶部开始，不裁字。

实测（1440×900）：Logo / 字标 / 诗句 / morph / 三个入口 / 页脚的水平中心全部落在 `x = 720`；
390×844 下全部落在 `x = 195`，上下留白 138 / 143。

### 5.2 诗句一行

去掉 `<br/>`，改 `white-space: nowrap` + `font-size: clamp(21px, 6.1vw, 46px)`：

- 1440 → 46px，整行宽 535px；
- 390 → 23.8px，整行宽 277px（可用 350px）；
- 320 → 21px，整行 248px，仍不折行。

### 5.3 三个入口

同宽（344/360）、同圆角、同高度节奏，靠材质分主次：

1. **打开数据包** — 墨底白字 + 阴影，主操作；
2. **从零开始** — 白底 + 1px 16% 描边，次操作（不用 0.5px 发丝线，否则看着像禁用）；
3. **先看看演示数据** — 独立卡片：38px 主题色图标块 + 双行文字 + 右箭头，
   副标题直接写「第一次使用？先用它体验全部功能」。

首次使用引导就落在这张卡的副标题上：不额外加横幅，也不弹提示。

## 6 修复：「设置 → 我的信息」双标题

设置页的 profile 分组直接渲染 `<ProfilePage />`，改标题后暴露出两层 `padding` 与重复大标题。

- `ProfilePage` 增加 `embedded` 参数：内嵌时不渲染 `PageHead`，容器加 `.page-embed`（`padding: 0`）；
- 设置页自己输出 `<h2>我的信息</h2>` + 一句说明，与「外观 / 数据包 / 隐私」等分组一致；
- 「我的名片」路由页标题改为「我的名片」，副标题说明数据去向；
- 顺手修掉名片页头像卡的 `linear-gradient(#fff,#f7f8fa)` 写死色值 —— 深色模式下原本会白成一块。
