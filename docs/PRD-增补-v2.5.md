> 范围：移动端设置页密度与二级结构、工具条图标回退、移动端滚动修复、互动记录排版、

## 0 修复：移动端页面滑不动

**现象**：移动端进入「人脉 / 互动 / 设置」后，内容比屏幕长也滑不动，只能看到第一屏。

**根因**：这三个路由的内容区用 `.content.no-pad { overflow: hidden }`，靠内部容器各自滚动
（桌面双栏就是靠这个固定高度）。移动端没有第二层滚动容器，长内容直接被裁掉。

**修复**：移动端把滚动权收回 `.content`：

- `.content.no-pad { overflow-y: auto; overflow-x: hidden }`；
- 副本内的 `.people-layout { height: auto; min-height: 100% }`、`.people-list-col` 与
  `.people-scroll` 改成自然高度、不自己滚。

**附带**：路由切换与进入设置二级页时把 `.content` 滚回顶部，避免「切页后停在上一页中间」。

**验收**：390 宽下工作台、设置清单、设置二级页（字段管理）真机手势可滑；人脉与互动灌入示例数据后可滑到底。

## 1 移动端设置页

十项排成**一整块**：共用一块玻璃底、无行间间隔、无分隔线，靠行高（76px）与图标尺寸

**规则**：返回只把 `settingsDetail` 置回 false，`settingsTab` 保留；从底部导航进设置永远落回清单。

## 5 启动页

**目标**：Apple 风格，极简。只留四件东西——图标、字标、一句诗、一条可点的说明。

**结构**

1. 84px 应用图标 + 「存知」字标（30px/700/−0.035em）+ 一行 13px 副标题；
2. 大字诗句「海内存知己，天涯若比邻。」`clamp(32px, 5.4vw, 58px)`，行高 1.2；
3. `InlineTextMorph`（compact 模式）：三行可点句子，点一次换词换贴纸；
4. 主按钮「打开数据包」、次按钮「从零开始」、文字入口「先看看演示数据」；
5. 底部一行 12px 说明：数据只写在你选中的文件里 · 不用注册 · 不上传服务器。

**移除**：原来的两段长文案、三张功能卡、浏览器能力说明段落。

**配色**：页面底色改为 `var(--surface)`（白 / 深色自动），只叠一层 7% 主题色顶光；
胶囊颜色用 `--itm-pill: color-mix(in srgb, var(--text) 9%, transparent)`，
深色下自动变成淡白底，不会出现「深字深底」。

**验收**：375 / 768 / 1440 无横向溢出；点击、键盘、减少动态、深浅两色均正常；控制台零报错。

## 6 组件：InlineTextMorph

详见 `docs/INLINE-TEXT-MORPH.md`。要点：

- 四文件：React 入口、框架无关引擎、动效运行时、类型声明；另附贴纸图形数据；
- 文字按 grapheme 拆分，LCS 优先保留相同字母的 DOM 身份，FLIP 从旧坐标滑到 0；
- 胶囊宽度弹簧（600/34/1，dt ≤ 1/30，4 子步）；
- 图标双层进出（300ms 过冲 1.1 / 140ms 收尾）；
- ShadowRoot 隔离，主题通过可继承的 `--itm-*` 变量渗透；
- 同页多实例、卸载无残留、减少动态可用、`aria-live` 播报。
