# PRD 增补 v2.7 —— 版式校正：去重、吸顶、可点的按钮

> 范围：全站（桌面 + 移动）。断点沿用 `max-width: 767px`，桌面指 `≥768px`。
> 本轮只改版式、层级与可辨识度，交互逻辑一行未动。

## 1 一屏只有一个标题

页面名重复出现是本轮最主要的问题，三处都来自「外壳」和「内容」各写了一遍。

### 1.1 桌面端顶栏不再写页面名

顶栏左侧原来是 `h1`（首页 / 人脉 / 互动 / 设置），内容区又有一个 30px 大标题。
**改法**：桌面端 `h1` 整块去掉，左侧让给数据包状态胶囊，右侧三个操作。

这样一屏只有内容区那一个大标题，顶栏变成纯工具栏 —— 与 apple.com 产品页一致。
手机上没有侧栏，顶栏仍是唯一的方位提示，`h1` 保留，页面内的 `PageHead` 用 CSS 隐藏。

### 1.2 「互动」统一为「互动记录」

侧栏、顶栏、页内大标题、底部导航四处原本两个名字。全部统一为**互动记录**，
侧栏宽度足够放下四个字。

### 1.3 设置页二级标题

| 位置 | 旧 | 新 |
|---|---|---|
| 顶栏 | 设置 | **分组名**（我的信息 / 外观 / …） |
| 返回条 | `‹ 设置` 面包屑 | `‹ 设置` 返回按钮（只说退到哪一层） |
| 正文 | `h2` 再写一遍分组名 | 手机端隐藏 |

桌面端保留左侧导航 + 右侧 `h2` 的主从结构（macOS 系统设置的惯例），不做改动。

### 1.4 数字与文案去重

| 位置 | 重复项 | 处理 |
|---|---|---|
| 人脉页 | 副标题「共 14 位人脉」+ 工具栏「14 人」 | 副标题改说筛选/待联系 |
| 人脉页 | 卡堆头「共 14 位人脉 · 按联系紧迫度排序」 | 只留「按联系紧迫度排序」 |
| 主题色卡 | 卡头「按钮、选中态、图标、图表都跟着变」+ 卡尾同义长句 | 卡头收短，卡尾只说默认值 |

## 2 移动端吸顶

### 2.1 人脉

搜索、智能视图、筛选、计数、排序、视图切换整合成一条 `sticky` 工具条，
`top: 0`，底色 84% 半透明 + 22px 毛玻璃，下边缘挂一层 10px 渐隐阴影表示「浮起来」。

前置条件：`app.css` 里 `.people-list-col` 是 `overflow: hidden`，会让 `sticky`
找不到滚动祖先而失效。移动端把它改成 `visible`，滚动权交回 `.content`。

实测：滑动 505px 后工具条 `top = 50`，恰为顶栏底边。

### 2.2 互动记录

同上。工具栏从四行压到三行（统计并进时间范围行，手机端隐藏），高度 240px。

## 3 移动端互动卡片

旧版把姓名、分组、正文、类型、渠道、时间、置顶、删除全塞在两三行里，
时间和两个操作按钮挤在右上角。

新版固定三层：

```
[头像] 张三  [同事]                    3 天前
       微信沟通：确认周五评审时间。
       [联系] 微信            [📌] [🗑]
```

| 变化 | 说明 |
|---|---|
| 时间上移 | 从底部 meta 行移到姓名行右端（`margin-left:auto`），与桌面端一致 |
| 正文限 3 行 | 再长就点进详情，列表只负责扫读 |
| 操作下沉 | 图钉 / 删除改绝对定位到卡片右下角，`bottom: 9px` |
| 日期分组 | 12.5px / 650 的小节标题，与卡片间距 8px |

## 4 侧栏折叠

### 4.1 折叠后图标消失（Bug）

`app.css` 用一条 `span:not(.dot-mark)` 统一「视觉隐藏」折叠后的文字（`clip-path: inset(50%)`）。
但灰阶立体图标 `GIcon` 渲染出来的根节点**也是 `<span class="gi">`**，
于是折叠后整条导航只剩三个色点 —— 一个按钮都点不到。

修复：`.sidebar.collapsed .nav-item span.gi` 单独放出来，恢复 `static` 尺寸；
图标从 17px 提到 20px，40px 的按钮里才压得住。

### 4.2 顶部按钮改成 logo

| 状态 | 旧 | 新 |
|---|---|---|
| 展开 | logo + 文字 + 折叠箭头 | 不变 |
| 折叠 | `brand` 被 `display: none`，只剩 15px 箭头 | 只显示 40×40 的 logo，**点它即展开** |

## 5 按钮可辨识

`apple.css` 第 3 节原本把 `.btn.icon` 清成 `background: transparent; box-shadow: none`，
结果顶栏三个图标、字段行的三个操作、卡片上的图钉与删除全部「飘」在白底上，
和装饰图标长得一样。

统一规则：

```css
.btn.icon,
.btn.icon.sm {
  background: color-mix(in srgb, var(--text) 7%, var(--surface));
  box-shadow: 0 0 0 0.5px color-mix(in srgb, var(--text) 13%, transparent);
}
```

| 类型 | 形态 | 举例 |
|---|---|---|
| 图标按钮 | 浅灰底 + 半像素描边 + 按下变深 | 顶栏搜索/速记/新建、排序、图钉、删除 |
| 文字按钮 | 主色墨底 / 白底描边 / 透明 | 新建人脉、导出 vCard、取消 |
| 信息标签 | 无描边浅色块 | 「联系」「同事」「3 天前」 |

不可用的图标按钮（锁定字段）**保持透明**：那一行是「不可用」，不是「可点」。

## 6 数据包状态

手机上原来只剩一颗 `led` 圆点，`background: transparent`、无文字，
用户既不知道它在说什么，也看不出能点。

| 断点 | 文案 | 形态 |
|---|---|---|
| 桌面 | 未关联本地数据包 / 已保存到数据包 | 6% 灰底胶囊，最左侧 |
| 手机 | 未存文件 / 已保存 | 暖色底胶囊，标题右侧 |

`no-file` 与 `error` / `dirty` 用 `#b45309` 暖色（深色模式 `#f0b45c`），
不再和「已保存」的绿色指示灯混淆。`title` 与 `aria-label` 补全为
「未存文件，点击打开数据包设置」。
