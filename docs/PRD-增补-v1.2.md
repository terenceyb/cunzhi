# 存知 · PRD 增补文档 v1.2

> 版本：v1.2　｜　基线：v1.1（2025-11）　｜　本轮覆盖：桌面端 6 项、移动端 5 项、两端共有 22 项、其他 2 项，共 35 项修改意见。
> 本文只记录**本轮新增与变更**的规则，未提及的条目沿用 v1.0 / v1.1。

---

## 0. 本轮的三条主线

1. **卡片即名片**：人脉不再只用表格/宫格罗列，新增 Wallet Card Stack 卡堆形态，桌面「卡片」视图与移动端人脉页都改用它；动效参数（400ms / cubic-bezier(.22,1,.36,1)）与 reduced-motion 兜底原样保留。
2. **浮层不抢空间**：人脉详情从"挤压列表"改为"悬浮在表格上方"的 liquid glass 面板；全局滚动条也改为浮在页面最上层的亚克力条。原则只有一句：**浮层永远不重排底下的内容**。
3. **一次交互只做一件事**：「已联系」不再静默写记录，而是先弹出互动记录；「配置列」不再点一下改一下，而是勾选后统一保存。

## 1. 桌面端

### 1.1 走动提醒的快捷操作恢复

**问题**：走动提醒行右侧的「已联系」「提醒」两个图标按钮在 hover 规则统一收进 `@media (hover: hover)` 时被误合并进选择器，导致按钮常驻隐藏。

**规则**
- 两个按钮回到默认可见；hover 只影响背景色，不影响 `display`。
- 图标语义不变：`已联系` 打开互动记录弹窗（见 3.1），`提醒` 打开待办的截止日期设置。

### 1.2 人脉「卡片」视图 = Wallet Card Stack

**来源**：transitions.dev Community 的 Wallet Card Stack，仅取**视觉与交互动效**，内容映射到人脉。

**卡片信息映射**

| 钱包卡元素 | 存知字段 |
|---|---|
| 卡名（Everyday） | 姓名 |
| 卡类型徽标（Debit） | 群组 |
| EMV 芯片 | 保留为装饰（关系"芯片"） |
| 卡号后四位 | 手机号后四位，前面 4 位以 `••••` 掩码 |
| 持卡人 | 公司与职位 |
| 品牌（Lumen） | 上次互动相对时间 |

**交互**
- 点击非前置卡：该卡提到最前，头部数字鼓轮转动，卡名文字做一次 blur 位移交换。
- 点击前置卡：展开/收起该人「详情」折叠区（职位、城市、上次互动、互动条数），卡堆高度 300ms 缓动变化。
- 鼠标 hover：卡片表面滑过一道 600ms 柔光（sheen），非前置卡抬升 4px。
- 按下：`scale(0.99)`，150ms。

**动效参数（保持原值，不做"差不多"的替换）**
- 卡堆位移/缩放：`400ms cubic-bezier(0.22, 1, 0.36, 1)`；peek 46px、tuck 8px、tuck-scale 0.045。
- 数字鼓轮：`327ms cubic-bezier(0.16, 1, 0.3, 1)`，逐位错峰 19ms，滚动中带 2px 纵向模糊。
- 折叠区：250ms 展开/收起，chevron 250ms 翻转。
- 文字交换：150ms，位移 4px + 2px 模糊。
- 全部动效在 `prefers-reduced-motion: reduce` 下 `transition: none`，鼓轮直接跳到目标位。

### 1.3 「配置列」改为勾选 + 保存

**旧行为**：点菜单项立刻增删一列，表格当场重排。
**新行为**
- 点击「配置列」在表格上方展开一块配置面板（200ms 上浮淡入）。
- 每个字段是一枚**复选框**（`role="checkbox"`），勾选/取消只改草稿，不动表格。
- 底部两个动作：「恢复默认」（7 个默认列）、「保存」。
- **只有点保存**才把草稿写入 `prefs.columnConfig` 并重排表格；取消则丢弃草稿。
- 「姓名」列锁定，不可取消勾选（否则表格失去主键锚点）。

### 1.4 表格细节

| 问题 | 规则 |
|---|---|
| 姓名列底色与其它列不一致 | 所有 `td` 统一 `var(--surface)`；姓名列作为 sticky 首列沿用同一底色，选中/hover 时与整行同步变色 |
| 只有公司可编辑，其它列不该能编辑 | 行内编辑只保留「公司/单位」；其余列点击不再进入编辑，只展示只读文本（超长截断 + title 全量） |
| 编辑框挤占其它列 | 编辑框改为**绝对定位覆盖**在单元格内（`left/right: 6px`），不改变单元格宽度；输入超出列宽时以 `text-overflow: ellipsis` 截断，不再把列撑开 |

### 1.5 详情浮层：liquid glass，不挤压列表

- 详情面板从"文档流内的第三列"改为 **absolute 浮层**，距容器上/右/下各 10px，宽度 `prefs.detailPanelWidth`（可拖拽左缘调整）。
- 视觉：`rgba(255,255,255,.72)` + `backdrop-filter: blur(30px) saturate(1.7)` + 顶部 1px 高光内阴影 + 大范围柔和投影，进入动画 260ms 从右侧 12px 处滑入并轻微放大到 1。
- 桌面≥768px 且当前视图是**流式布局**（卡片/宫格）时，列表滚动区右侧让出 `detailWidth + 26px`，避免内容被玻璃层压住；**表格视图不让位**，因为浮层本就在表格上方，滚动时内容从玻璃下穿过——这是刻意保留的层次感。

## 2. 移动端

### 2.1 人脉列表采用卡堆样式

- 移动端人脉页默认视图从宫格改为 **Wallet Card Stack**，一屏可见 3 张卡（`--w2-card-h: 164px`、`--w2-peek: 50px`）。
- 桌面「卡片」视图与移动端共用同一组件与同一套动效参数，只换尺寸变量。
- 移动端不启用 hover 相关效果（sheen/抬升），改为按下 `scale(0.99)`；`touch-action` 保持默认，不阻断竖向滚动。

### 2.2 底部导航：liquid glass 悬浮

- 导航条不再贴底满宽：改为距屏幕左右 12px、底部 `12px + safe-area` 的悬浮胶囊，圆角 22px，背景 `rgba(255,255,255,.62)` + `backdrop-filter: blur(24px) saturate(1.8)` + 细描边 + 上抛阴影。
- 内容区底部留白 `84px + safe-area`，保证最后一屏内容不被胶囊压住。

### 2.3 最后一张卡被导航覆盖

- `.people-scroll` 底部内边距改为 `calc(104px + var(--safe-b))`，`tight` 变体同样保留该留白。
- 结论：滚到底时最后一张卡完整可见，与胶囊之间始终留 ≥ 8px 空隙。

### 2.4 页面标题偏小

- 顶栏标题 15px → **19px / 650 字重 / -0.02em**；顶栏高度 52px → 54px。移动端标题是唯一的定位锚点，需要分量。

### 2.5 点按区域与密度

- 按钮最小高度：常规 38px、`sm` 34px；chip 30px；提醒行 padding 9px → 11px；待办行 10px。
- 密度靠留白而不是压缩行高：一屏信息量减少约 8%，但可点区域全部 ≥ 34px。

## 3. 两端共有

### 3.1 「已联系」改为记录互动

- 点击不再直接写一条无内容的时间线记录，而是打开**互动记录弹窗**：方式（电话/见面/微信/邮件/短信/礼物）、时间、内容、是否重置提醒计时。
- 保存后才写入该人脉的互动时间线，并按 `reminderPolicy` 重置走动计时；取消不产生任何记录。
- 礼物方式额外要求填写「礼物名称 / 价值」，写入时间线 `gift` 类型。

### 3.2 互动方式可自定义，且必须有「礼物」

- 时间线的记录入口从下拉框改为**方式胶囊组**：电话、见面、微信、邮件、短信、礼物（默认六种）。
- 末尾「+ 自定义」：输入新方式（如「飞书」「咖啡」）后写入 `prefs.channels`，立刻成为可选项，全局生效。
- 方式选择与记录输入在同一行内完成，不再需要先选下拉再输入。

### 3.3 滚动条浮层化

- 原生滚动条宽度归零，改由自绘的**悬浮亚克力 thumb**（7px 宽、`backdrop-filter: blur(8px)`、内描边高光）浮在页面最上层。
- 行为：滚动时淡入，停止 1.1s 后淡出；支持按住拖动；位置按滚动比例映射，不参与任何布局计算。
- 因此内容区宽度不再被滚动条吃掉，也不会遮挡内容（thumb 只在右缘 3px 处出现）。
- reduced-motion 下取消淡入淡出过渡。

### 3.4 速记的「关联到」

| 问题 | 规则 |
|---|---|
| 推荐人脉缺少"可选中"的提示 | 每枚推荐 chip 右侧加一个虚线圆圈：未选中显示 `+`，点击后变成实心强调色的 `✓`；chip 本身同时变为强调色描边 + 浅底。再次点击可取消 |
| 关联前后呈现不一致 | 上方「已关联」区与下方「关联到」推荐使用**同一套 chip 结构**（头像 22px + 姓名 + 公司 + 右侧标记），高度同为 30px，只差选中态颜色 |

### 3.5 截止日期弹窗离输入框太远

- 原生日期选择器的锚点元素从"输入框右下角 1px 探针"改为**覆盖在输入框左下角的 34×30 命中区**，弹窗从输入框边缘展开，不再飘到字段下方。

### 3.6 删除生日祝福复制

- 纪念日卡片右侧的「复制生日祝福语」按钮移除；纪念日仍可编辑、可跳转到对应人脉。

### 3.7 删除四个统计项

- 工作台移除「人脉总数」「本周已联系」「待办完成率」「最近备份」四个统计 pill。工作台首屏让位给三张真正需要动作的卡片。

### 3.8 卡片可调整大小与位置

- 三张卡片（走动提醒 / 待办事项 / 纪念日）可拖拽排序、可拖右下角调整尺寸；布局写入 `prefs.dashLayout`。
- **不重叠**：拖拽与缩放时按列堆叠计算，落位自动吸附，禁止卡片相互覆盖。
- 顶部提供「恢复默认布局」，一键清空 `prefs.dashLayout` 回到出厂排布。

### 3.9 新建人脉弹窗

- **头像**：弹窗内直接上传（走统一上传弹窗，见 4.1），上传后即时预览，保存时写入附件。
- **爱好**：可作为自定义字段自由填写。
- **爱好 / 群组 / 标签**：统一改为**可输入也可下拉**的选择器——
  - 聚焦即展开候选，输入关键字过滤；
  - 输入内容不存在时，下拉底部出现「新建「xxx」」，回车即创建并选中；
  - 输入内容与已有选项同名（忽略大小写）时，直接选中已有项，不产生重复。
- 原有的「新建」按钮与二次弹窗取消，创建动作收敛到下拉里一步完成。

### 3.10 删除全局名片码

- 全局「名片码」入口与相关设置项一并移除；单人名片导出（vCard / 名片册打印）保留。

### 3.11 工作台底部提示固定

- 底部提示文字固定贴在内容区可视底部（`position: sticky; bottom: 0`），文案不变，滚动时始终可见。

### 3.12 多选不挤压行内容

- 多选模式下复选框**覆盖在头像上**（绝对定位 + 半透明底 + 白色描边），不再插入到行首。行的内容位置保持不变，因此不会出现"整体右移"的跳动。

### 3.13 删除重复按钮

- 工作台内「速记」「+ 新建人脉」两个按钮删除，只保留顶栏的搜索、速记、新建三个图标按钮。

### 3.14 未关联状态文案与位置

- `本次会话未关联文件` → **`未关联本地数据包`**；状态胶囊移到搜索图标左侧。

### 3.15 筛选条件不再线框套线框

- 条件行外层去掉边框，只保留浅底；线框交给内部的字段/操作符/值控件。视觉上从"两层框"变成"一条浅色槽 + 三个控件"。

### 3.16 设置 · 我的信息

- 页面标题由「我的名片」改为 **「我的信息」**，与入口一致。
- 删除：标题下的说明段、"一句话介绍"字段、"地址"字段、`保存即写入数据包 settings.profile` 提示、页尾关于「我 vs 他们」的长段说明。

### 3.17 设置 · 字段管理

| 问题 | 规则 |
|---|---|
| 拖动时不跟手、无落位反馈 | 拖拽中源行降为 40% 透明；目标行顶部出现 2px 强调色插入线 + 浅底，并用 3px 的高度让位做「挤占」过渡（160ms） |
| 字段中间显示英文 key | 删除 `def.key` 展示，只留「类型 · 使用 N 人」 |
| 锁定字段仍可改名、可点叹号 | 锁定字段的名称输入框 `readOnly`、右侧配置按钮 `disabled`（不可聚焦、不可点） |
| 「锁定」徽标离名称太远 | 名称输入框宽度按字数自适应（`ch` 单位），徽标紧贴其后，间距固定 5px |
| 字段定义导入无用 | 删除「字段定义导入」整张卡片；「导出定义」保留 |

### 3.18 设置 · 数据包管理

- 两段说明合并到原第二段的位置，默认折叠，只显示一行红字 **`* 点击查看数据包管理须知`**；点击后 250ms 网格展开（`grid-template-rows: 0fr → 1fr`）。
- 「关闭数据包」改为危险按钮（浅红底 + 红字 + 红描边）。
- 快照行改为 `info（flex:1, min-width:0） + 操作按钮（flex:0 0 auto）`，说明文字允许换行，恢复按钮不再挤压快照信息。

### 3.19 人脉详情页

**一、字段名只出现一次**：编辑态不再渲染 `FieldBlock` 的 label（`hideLabel`），左侧字段名是唯一标识；编辑区直接从输入控件开始。

**二、编辑区可读性**
- 行高 32px → 44px（空字段 34px），字段之间不再上下挤占、点击编辑时其他字段不位移。
- 字段名 12.5px / `--text-3`，值 13.5px / 22px 行高 / `--text`；进入编辑时整行底色变为 `--surface-2`，边框由内层控件承担。
- 只读态 hover 出现浅底与铅笔提示，明确"可点"。

**三、联系方式**
- 电话/邮箱的每一行统一为 `标签（34px 固定） + 值（flex:1，超长省略） + 操作组（margin-left:auto）`，拨号/短信/复制三个按钮**右对齐**，与号码同一基线。
- 新增「+ 更多方式」菜单，一键添加国内外主流通讯方式字段：微信、WhatsApp、Telegram、LINE、QQ、钉钉、飞书、Signal、X / Twitter、Instagram、座机。已添加的显示「（已添加）」并禁用。

### 3.20 字段图标

- 每个字段前置一枚 13px 图标，来源 **Remix Icon**（Apache-2.0），以内联 path 引入，不新增字体或网络请求。
- 映射规则：先按字段 key 精确匹配（姓名→user、电话→smartphone、生日→cake、公司→building、爱好→basketball、群组→group…），再按字段类型兜底（text→file-text、date→calendar、number→calculator…）。

### 3.21 空字段高度

- 显示空字段时，空行高度压到 34px、字号降到 12.5px、去掉上下多余内边距，让"未填写"保持可点但不占视野。

### 3.22 走动提醒的姓名 / 群组 / 上次互动对齐

- 三者改为同一列内的垂直堆叠（姓名在上，群组与上次互动在下行），群组在左、上次互动时间紧邻其右，左缘对齐，不再一左一右分散。

## 4. 其他

### 4.1 全局上传弹窗

**来源**：transitions.dev Community 的 Upload modal，保留其全部动效，替换为存知的设计 token。

- 触发：所有需要选文件的地方（附件、头像、导入）统一调 `openUpload()`，不再各自弹原生文件框。
- 流程：打开 → 「选择文件」→ 显示文件行（名称 / 大小 / 状态）→「上传」→ 进度条推进 → 图标换成对勾、文案换成「已完成」→「完成」关闭并回传文件。
- 支持拖放。
- 动效：开 250ms / 关 150ms、`scale(0.96)`、`cubic-bezier(.22,1,.36,1)`；图标交换 250ms（缩放 0.25 + 2px 模糊）；按钮文案交换 150ms（位移 4px + 模糊）；进度条 150ms；按下 0.97。reduced-motion 下全部瞬时。

### 4.2 应用图标重设计

- 从"多人结点 + 连线"的具体插画，改为**单一几何符号**：深墨渐变圆角方（#2B3138 → #0C0F12）+ 一枚留缺口的白色圆环 + 环心实心圆点，缺口落在右上方 45°。
- 意味着「一条未闭合的关系轨道 + 中心的那个人」——开放、可持续维护，也便于在 16px 下辨认。
- 交付：`icon-512/256/192.png`、`apple-touch-icon.png`、`favicon.svg`、`logo.svg` 全部同构重绘；manifest 与 HTML 引用不变。

## 6. 已知取舍

1. **表格视图下详情浮层会盖住右侧列**：这是"不挤压列表"的直接代价。流式视图已自动让位，表格视图保留遮挡——拖左缘可调宽度，`Esc` 关闭。
2. **卡堆在 60+ 人时不如表格高效**：所以桌面端保留表格/宫格/关系网三种视图，卡堆只是其中之一；移动端只提供卡堆与关系网。
3. **悬浮滚动条是自绘的**：触摸板惯性滚动、键盘 PageDown 都正常，但浏览器原生"滚动条拖到指定位置"的行为由自绘 thumb 复刻，极端快速拖拽下位置可能有 ±1px 误差。
4. **字段图标是内联 path**：新增字段会落到类型兜底图标，若需要专属图标，需在 `FieldIcon.tsx` 的 `BY_KEY` 中补一行映射。
